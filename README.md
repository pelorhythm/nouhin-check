# 納品チェック

映像の納品前チェックを2段階で自動化するツール。ファイルをドラッグ&ドロップするだけで使える。

| 段階 | ドロップするもの | 検出内容 |
|---|---|---|
| **書き出し前** | Premiereの `.prproj` | 黒パカ疑い（1〜2Fの隙間）／カット点の±1〜2Fズレ（テロップのこぼれ・抜け）／無効化クリップの取り残し／空白 — シーケンスタイムコード付きリストで表示 |
| **書き出し後** | 書き出した `.mp4` / `.mov` 等 | 尺・解像度・fps・コーデック／ラウドネス(LUFS)・トゥルーピーク／黒フレーム・無音の実測。納品先（YouTube / TV放送 / Web広告）の基準で判定 |

結果はブラウザで開くレポート（HTML）と、同じ内容のテキストファイルとして、ドロップしたファイルの隣に自動保存される。

---

## 導入（Mac）

1. このリポジトリをダウンロードする
   （緑の「Code」ボタン → **Download ZIP** → 解凍。フォルダごと好きな場所に置く）
2. `mac/納品チェック.app` を**右クリック → 開く**（初回のみ。ダウンロードしたアプリのため確認が出る）
3. 書き出し後チェックを使う場合は ffmpeg が必要。ターミナルで:

   ```
   brew install ffmpeg
   ```

   ※ 書き出し前チェック（.prproj）だけなら ffmpeg 不要。

**注意**: アプリだけを別の場所にコピーしない（解析プログラム本体は `scripts/` にあり、アプリはそれを呼ぶ受け口のため）。
よく使うなら、アプリを **Dockにドラッグ** するか、右クリック → エイリアスを作成してデスクトップに置く。

## 導入（Windows）

1. リポジトリをダウンロード（Macと同様）
2. [Python 3](https://www.python.org/downloads/) をインストール（インストーラで **「Add Python to PATH」に必ずチェック**）
3. 書き出し後チェックを使う場合は PowerShell で:

   ```
   winget install Gyan.FFmpeg
   ```

   実行後、一度サインアウト（または再起動）する。
4. `scripts/nouhin-check.bat` を右クリック → **ショートカットの作成** → デスクトップに置く

使う時は、そのショートカットにファイルをドロップする。

---

## 使い方

- **`.prproj` をドロップ** → シーケンスを選ぶ → タイムライン構造の解析結果が開く
- **動画ファイルをドロップ**（複数可・連番もまとめて可） → 納品先を選ぶ（YouTube/SNS・TV放送・Web広告） → 指定尺を任意入力（CM枠などの時だけ） → 実測結果が開く

### コマンドラインから使う場合

```bash
# 書き出し前（シーケンス一覧 → 解析）
python3 scripts/precheck.py <prproj> --list
python3 scripts/precheck.py <prproj> --sequence 4

# 書き出し後
python3 scripts/check.py <動画ファイル> --target youtube|broadcast|web [--duration 30]
```

---

## 判定基準

| 納品先 | ラウドネス | トゥルーピーク |
|---|---|---|
| YouTube / SNS | -14 LUFS ±1 | -1.0 dBTP |
| 日本のTV放送・CM（ARIB TR-B32） | -24.0 LKFS ±1 | -1.0 dBTP |
| Web広告 汎用 | -16 LUFS ±1 | -1.0 dBTP |

基準値・検出ロジックは `scripts/check.py`（実測系）と `scripts/precheck.py`（構造系）が単一ソース。

## 制約・注意

- 機械で測れる項目のみ。**最終確認は人の目と耳で。**
- `.prproj` は Adobe の非公開仕様のため、Premiere のメジャーアップデートで解析が動かなくなる可能性がある
- DaVinci Resolve のプロジェクト解析は非対応（書き出し後チェックは使える）
